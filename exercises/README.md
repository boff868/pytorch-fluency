# 默写与毕业练习

这里故意不给代码骨架。真正的目标是把问题拆成可写的块，而不是补全模板。

## 练习 1：形状口算

给定 `x.shape == [16, 3, 32, 32]`：

1. `x.flatten(1)` 的形状是什么？
2. `Conv2d(3, 8, kernel_size=3, padding=1)` 后是什么？
3. 再过 `MaxPool2d(2)` 后是什么？
4. 怎样把 `[16, 8, 1, 1]` 变成 `[16, 8]`，且不写死 batch size？
5. 为什么对 `[16, 1]` 与 `[16]` 直接做减法很危险？

验收：先写答案，再用随机张量和真实层验证。

## 练习 2：从零写 MLP

输入 `[B, 12]`，输出 5 类 logits。要求：

- 两个隐藏层，宽度自己选择；
- 至少一个非线性层；
- 不在末尾使用 Softmax；
- 用 `[7, 12]` 的 dummy batch 验证输出为 `[7, 5]`；
- 打印总参数量。

## 练习 3：默写训练循环

在 15 分钟内从空白文件写一个函数，参数为 `model, loader, loss_fn, optimizer, device`，返回样本加权的 loss 和 accuracy。

不能漏：

- 训练模式；
- batch 搬设备；
- 前向、loss、清梯度、反传、更新；
- 不把带计算图的 tensor 存一整个 epoch；
- 最后一个小 batch 权重正确。

## 练习 4：由训练循环改出验证循环

复制你刚写的训练函数，改成验证函数。完成后解释：

1. 删除了哪三步？
2. 为什么 `model.eval()` 还不够？
3. 为什么 `torch.inference_mode()` 不能包住训练？

## 练习 5：单 batch 过拟合

从 DataLoader 取一个不超过 32 个样本的 batch，重复训练 300 次。记录第 1、10、50、100、300 步的 loss 和 accuracy。

如果达不到接近 100%：只允许一次改变一个因素，并记录假设与证据。

## 练习 6：调试演习

对一份可训练代码依次故意加入以下 bug，每次用最小复现定位：

1. 把多分类标签从 `long` 改成 `float`；
2. 只把模型搬到设备，不搬 batch；
3. 忘记 `optimizer.step()`；
4. 在 loss 前对 logits `.detach()`；
5. 在模型结尾加 Softmax，却仍用 CrossEntropyLoss；
6. 验证时忘记 `model.eval()`；
7. 让回归预测为 `[B, 1]`、标签为 `[B]`。

对每个 bug 写：症状、根因、最早能捕获它的断言。

## 毕业题：独立完成三分类项目

不查看 `labs/03_train_classifier.py`，创建一个全新脚本：

1. 用纯 PyTorch 生成不少于 900 个二维点，分成 3 类；
2. 划分训练集和验证集，使用 DataLoader；
3. 写一个至少含两个 `Linear` 层的 `nn.Module`；
4. 写独立的 `train_one_epoch` 和 `evaluate`；
5. 先证明模型能过拟合一个 32 样本 batch；
6. 完整训练并输出每轮 train/validation loss 与 accuracy；
7. 只在 validation loss 改善时保存 checkpoint；
8. 新建模型实例并加载 checkpoint；
9. 证明加载前后对同一输入的 logits 一致；
10. 写 5 行实验结论：是否欠拟合/过拟合，下一步只改哪个变量，为什么。
